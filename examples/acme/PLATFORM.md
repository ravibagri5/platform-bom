## Why build on the Acme platform?

Teams on the platform go from repository to production in a day, not a quarter.
We run and upgrade the building blocks so you don't have to.

| You bring              | The platform provides                                  |
| ---------------------- | ------------------------------------------------------ |
| A container image      | Deployment, scaling, rollout and rollback via GitOps   |
| A claim for a database | A managed PostgreSQL instance with credentials synced  |
| An HTTP service        | mTLS, ingress, certificates and DNS                    |
| Nothing                | Metrics, alerts and dashboards for every workload      |
